# Hadoti (हाड़ौती) Dataset Specification

## Overview
Hadoti is spoken in the Hadoti region of South-Eastern Rajasthan (Kota, Bundi, Baran, Jhalawar).

## Metadata Summary
- **Dataset Name:** Hadoti Speech & Text Corpus
- **Source:** VAANI / Local Archives
- **License:** CC-BY-4.0
- **Language Code:** `raj_had` (ISO 639-3: `hoj`)
- **Speech Audio Duration:** ~25 Hours
- **Sampling Rate:** 16,000 Hz
- **Text Script:** Devanagari
- **Train/Val/Test Split:** 80% / 10% / 10%
