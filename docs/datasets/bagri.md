# Bagri (बागड़ी) Dataset Specification

## Overview
Bagri is spoken in North-Western Rajasthan (Sri Ganganagar, Hanumangarh) bridging Rajasthani and Punjabi.

## Metadata Summary
- **Dataset Name:** Bagri Speech & Parallel MT Corpus
- **Source:** VAANI (ARTPARK-IISc)
- **License:** CC-BY-4.0
- **Language Code:** ISO 639-3 `bgq`
- **Speech Audio Duration — TARGET:** ~60 hours
- **Speech Audio Duration — ACTUAL:** **0 hours.** No audio file for this dialect exists in the repository.
- **Sampling Rate:** 16,000 Hz
- **Text Script:** Devanagari
- **Train/Val/Test Split (planned):** 80% / 10% / 10% — not yet created

## Collection Status

**Nothing in this document is a description of collected data.** It is a specification of
what to collect. `data/raw/vaani/` is empty; the cached Karya rows are text-only and carry
no dialect label.
