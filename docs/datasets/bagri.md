# Bagri (बागड़ी) Dataset Specification

## Overview
Bagri is spoken in North-Western Rajasthan (Sri Ganganagar, Hanumangarh) bridging Rajasthani and Punjabi.

## Metadata Summary
- **Dataset Name:** Bagri Speech & Parallel MT Corpus
- **Source:** VAANI (ARTPARK-IISc)
- **License:** CC-BY-4.0
- **Language Code:** `bgq` (ISO 639-3: `bgq`)
- **Speech Audio Duration:** ~60 Hours
- **Sampling Rate:** 16,000 Hz
- **Text Script:** Devanagari
- **Train/Val/Test Split:** 80% / 10% / 10%
