# Mewati (मेवाती) Dataset Specification

## Overview
Mewati is spoken in the Mewat region of North-Eastern Rajasthan (Alwar, Bharatpur) bordering Haryana.

## Metadata Summary
- **Dataset Name:** Mewati Speech & Text Corpus
- **Source:** VAANI
- **License:** CC-BY-4.0
- **Language Code:** `raj_mwt` (ISO 639-3: `wtm`)
- **Speech Audio Duration:** ~20 Hours
- **Sampling Rate:** 16,000 Hz
- **Text Script:** Devanagari
- **Train/Val/Test Split:** 80% / 10% / 10%
