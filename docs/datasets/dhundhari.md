# Dhundhari (ढूंढाड़ी) Dataset Specification

## Overview
Dhundhari is spoken in the Dhundhar region of Eastern Rajasthan (Jaipur, Dausa, Tonk, Sawai Madhopur).

## Metadata Summary
- **Dataset Name:** Dhundhari Speech & Parallel MT Corpus
- **Source:** Karya / VAANI
- **License:** CC-BY-NC-4.0
- **Language Code:** `raj_dhu` (ISO 639-3: `dhd`)
- **Speech Audio Duration:** ~50 Hours
- **Sampling Rate:** 16,000 Hz
- **Text Script:** Devanagari
- **Train/Val/Test Split:** 80% / 10% / 10%
